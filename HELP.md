# Sistema web de tienda

Proyecto de tienda creado con Spring Boot, Java 17, JSP y base de datos H2.

## Requisitos

- Java 17 o superior.
- Conexión a Internet la primera vez que se use Maven Wrapper, para descargar Maven y sus dependencias.

## Ejecutar en Windows

Desde esta carpeta, abre una terminal y ejecuta:

```text
mvnw.cmd spring-boot:run
```

La aplicación se abre en http://localhost:8086/.

También puedes abrir el proyecto desde IntelliJ IDEA seleccionando esta carpeta y esperar a que Maven cargue las dependencias.
